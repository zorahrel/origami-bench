🦢 origami-bench

One prompt, 12,000 tokens, one HTML file, actually run and scored on video. Tap a model or a task.

Ranking, mean of 4 tasks

    Score 1-10 · total generation time · one run per cell, under ~1 point is a tie.

    How it works

    Every model gets the same short prompt per task and must return one self-contained HTML file (three.js r170) under 12,000 output tokens. Each file is rendered headless in WebKit for 15 s; a panel of three vendor-diverse video judges (gpt-6-luna, Gemini via a free router, claude-haiku-5-5) scores 1-10 against a fixed rubric; capped at 4 if nothing moves.

    Effort. Every model ran at its maximum: Claude --effort max, Codex model_reasoning_effort=xhigh, Muse --reasoning-effort ultra; free-auto has no setting.

    Tokens. Claude and Codex counts include hidden reasoning, so most cells show as over budget; the HTML itself is always under 32 KB. Muse counts are estimated from characters.

    Judge agreement: codex–router: r=0.88, gap 1.7 pt; codex–claude: r=0.94, gap 0.5 pt; router–claude: r=0.85, gap 2.2 pt. The Gemini judge is the most lenient; Claude and GPT models also compete, hence the panel.
